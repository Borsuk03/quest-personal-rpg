# QUEST — Personal RPG

Osobista aplikacja webowa (PWA) do ręcznego zapisywania dnia, nauki, pracy i projektów.

## Funkcje
- 4 obszary: Codzienność, Praca i skupienie, Akademia, Warsztat twórcy.
- Biblioteka aktywności i projektów z możliwością edycji.
- Rejestrowanie wykonanych aktywności, daty, czasu i notatek.
- Tryby pracy: intensywny, krótki, wolny.
- Dziennik, statystyki ostatnich 7 dni, punkty XP i poziomy.
- Dzień może kończyć się o 05:00 zamiast północy.
- Dane lokalne (localStorage) i kopie JSON.
- PWA z podstawowym cache offline.

## Uruchomienie przez GitHub Pages
Repozytorium → Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save.

Po uruchomieniu: https://borsuk03.github.io/quest-personal-rpg/

## Ważne
GitHub Pages nie synchronizuje danych między urządzeniami. Nie zapisuj w aplikacji haseł ani wrażliwych informacji. Kopie JSON zawierają notatki użytkownika.
